The Godot 4.5.1 spikes support the room shader, bundled fonts, and dateline audio. The blockers are in how those pieces attach to the live game and how the build verifies them. [Spike results](/home/alex/code/pdoom1/fork/design/godot-g/spikes/RESULTS.md)

## Blocking items

1. **The G layout cannot complete the specified boot sequence.** `MainUI._apply_ui_layout()` still coerces `"g"` to `"classic"`. The spec also reparents live controls before it creates their destination sheets, and the boot-time layout call runs before `_inflight_hiring_box` exists. Move layout application after host construction, accept `"g"` in both dispatchers, instantiate the desk before moving controls, and seed it from the current UI state on a live flip. On exit, restore the current PLAN/WATCH visibility and reparent controls before freeing the desk. Test boot directly into persisted G as well as F9 flips from both existing layouts. 2. **The sheet and guide recipes leave keyboard and modal ownership unresolved.** The proposed Escape callback depends on a host and registered stack entry, but the escape-contract test instantiates panels standalone and calls `show_panel()`. In the live game, the existing modal router consumes all unrecognized keys before GUI focus handling, so the spec's keyboard-focused action rows have no Tab path. The embedded guide also inherits its own `_input` Escape handler. Make each sheet close independently, route live closes through `ModalStack`, disable input immediately during a close fade, and keep focus traversal inside the top sheet. Give the embedded guide the same barrier and ownership rules. Pass the G row anchor through the shared action path for both clicks and slots, and guard deferred door return against a layout flip, scene exit, or newer modal. Test Escape mid-tween, Tab within a sheet, and an event replacing an open sheet. Likewise, use the existing unrounded affordability and aggregate-plus-typed Attention checks for action admission. Round only the displayed amounts. Route rejections to a visible G toast, since the current toast sits inside the PlanScreen that G hides. Add parity cases for an empty queue, a reserved aggregate pool, and an unaffordable action.
